Static map internals

The static map builder (fallout build --static) and its inference walk.

Fallout.StaticMap.CONTAINER_BUILDERS — Constant

The Base functions that build a container from what they are handed and call only the function they are handed (the one inside a Generator), never a value the container holds.

source
Fallout.StaticMap.IDENTIFIER — Constant

Matches an identifier, with unicode letters, digits and the trailing ! Julia names allow, that no @ or letter precedes (a macro's name is not a function's).

source
Fallout.StaticMap.RUNTIME_CALLEES — Constant

The functions that run code chosen at run time: invokelatest and eval and the builtins they inline to.

source
Fallout.StaticMap.TESTSETS_PER_WORKER — Constant

Testsets that make another worker process worth its start-up (loading the test module takes about 20 s).

source
Fallout.StaticMap.TYPE_INSPECTORS — Constant

The Base and compiler functions that take a function and argument types and only look the method up or infer it, never calling the function: the type of a memo_types memo is inferred this way from the filing solve's own functions.

source
Fallout.StaticMap.WORKER_MEMORY — Constant

Memory a worker process needs: the test module, the compiled bodies and the inferred frames of its testsets.

source
Fallout.StaticMap.BodyOutcome — Type

A body compiled as a function: its signature, or why it did not compile (failure empty when it did).

source
Fallout.StaticMap.CacheEnvelope — Type

A serialized Salsa storage with an environment fingerprint.

source
Fallout.StaticMap.Definition — Type

One function of a tracked file: where it sits and the hash of its parsed code.

source
Fallout.StaticMap.DropTestsets — Type

Drop top-level testset calls while loading definitions from test files. A testset inside a function definition (a helper that runs one) is replaced by its body instead, as in a compiled testset body, so the helper still reaches what its testset calls.

source
Fallout.StaticMap.DropUnresolved — Type

What a walk does at an unresolved call site: drop the edge and count it.

source
Fallout.StaticMap.FileInventory — Type

The part of a tracked file that is not a testset: its functions, the identifiers each function mentions, its other items, and the code of each name its bindings define.

source
Fallout.StaticMap.FilePlaces — Type

A tracked file's functions, found by line: first lines ascending, with each function's last line and Definition number.

source
Fallout.StaticMap.FoldedCalls — Type

A walk frame that reads only the folded and dead calls of signature S (folded_edges): a scope function called by name may be inlined, which leaves its live calls in its caller's IR and its dead branches nowhere. Walking it as a whole frame would also count the values it returns as handed to outside code, which they are not.

source
Fallout.StaticMap.FollowKnown — Type

What a walk does at an unresolved call site: follow every method in scope that can match a known callee.

source
Fallout.StaticMap.FollowUnresolved — Type

What a walk does at an unresolved call site: follow every method that can match, and reach all source from an unknown callee.

source
Fallout.StaticMap.FrameEdges — Type

What one frame's IR calls: methods reached, signatures to walk next, one label per unresolved site, and the inference edges its types were inferred from (dependencies).

source
Fallout.StaticMap.FrameRecord — Type

What a frame reached, as Definition numbers rather than Methods so a cache can hold it.

source
Fallout.StaticMap.Options — Type

What build was asked for.

source
Fallout.StaticMap.OtherItem — Type

A tracked file's item that is neither a function nor a testset (a struct, constant, macro, include, a call at top level), kept by the hash of its code: its name (empty for an item that defines none) and the identifiers it mentions, one entry per occurrence.

source
Fallout.StaticMap.OutsideCollector — Type

Collects, from Base.visit over the method table, the outside and owned indexes of a Scope of modules.

source
Fallout.StaticMap.OutsideCollector — Method

Index method when it is a scope method of a function or a constructor owned outside the scope.

source
Fallout.StaticMap.PartialWalk — Type

A worker's testset reach results and query counts.

source
Fallout.StaticMap.Placements — Type

Where methods are: the root their files are relative to, every tracked file's functions, and each method's file and line once found (Revise's line lookup parses the file, which a walk of tens of thousands of frames repeats for the same few thousand methods).

Fallout.StaticMap.folded_edges — Method

What the calls of signature that inference folds to a constant or never reaches run, read from the unoptimized IR: the optimizer replaces a folded call by its value and deletes a dead branch, keeping no trace of either in the IR or its debug info. Each scope function the frame calls by name gets a FoldedCalls frame, which finds the dead branches of an inlined callee (a branch past differentiating()).
